# Sayful — Releases

Public releases of **[Sayful](https://sayful.app)** — a macOS menu-bar writing assistant:
AI dictation in any app (EN/UK/RU), wrong-keyboard-layout autocorrect, on-the-spot
translation, screen OCR, read-aloud and custom AI text transforms.

**[Download the latest .dmg →](https://github.com/MikeKorotych/sayful-releases/releases/latest)**

Requires macOS · Apple Silicon & Intel.

The application source is developed in a private repository; this repo hosts
distribution builds and release notes only.
